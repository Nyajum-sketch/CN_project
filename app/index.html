Design and Implementation of a Secure Smart University Campus Network

Course: Computer Networks Laboratory Mini Project (CS8581 / CS3591)

This project provides a complete, mathematically verified, and simulation-tested campus digital infrastructure. All 17 subnets have been designed under VLSM with zero overlaps, dual-router high availability is enforced via HSRP, dynamic routing is orchestrated by Multi-Area OSPF with Area 1 summarization, core applications (Web, Mail, DNS, FTP) are fully operational, and end-to-end security is guaranteed through Port Security, ACLs, and Site-to-Site IPsec VPN tunneling.
